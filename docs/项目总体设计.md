## 二、项目定位（一句话）

> **AetherServe：面向大模型的多租户推理服务平台。以 OpenAI 兼容协议对外提供服务，
> 通过自研连续批处理网关提升 GPU 吞吐，通过 Kubernetes Operator 实现推理服务的声明式管理与弹性伸缩，
> 通过 GPU 感知调度器提升显存装箱率。**

### 数据流（一次流式推理请求）

```
Client ──POST /v1/chat/completions(stream=true)──▶ Gateway
   Gateway: 鉴权 → 限流 → 选后端 → 构造 BatchRequest ──▶ BatchingEngine.enqueue()
   BatchingEngine: 入优先级队列 → 调度器按 (显存水位, 批大小上限, 等待时延) 构建 Batch
        ──▶ Backend.generate(batch) ──▶ vLLM(连续批处理, PagedAttention)
        ◀── token 流 (按 request_id 多路分解)
   Gateway ◀── 逐 token 封装为 SSE data: {...}\n\n ──▶ Client
   Metrics: 每个阶段打点 (queue_wait_ms, batch_size, ttft_ms, tpot_ms)
```
